# Suna
## About Suna:
#### Suna is a web application which can be used for you to just chill and listen songs, find your mood and get the song suggested and vibe on it and more. You can play different songs, explore albums by popular artist and do much more stuffs here. It has so much features which are given below.

<hr>

## Features:
- Listen Songs while having play, pause, rewind features.
- Find your mood and get the song related to it.
- Find the treasure song by looking at the lyrics.
- Explore different songs which are categorized into their artist.
- Has a points system where you get points for guessing the song.
- Gives Suna Ball knowldge d'or for reaching a fixed number of points after guessing.

<hr>

## Tech Stack:
- <b> Node/Express Js </b>: Used for backend coding and dealing with many POST requets.
- <b>HTML</b>: Used for making the structure of all the web pages.
- <b>CSS</b>: Used for styling the web pages and making them attractive.
- <b>JS</b>: Used for sending POST requests, receiving them, processing them, handling the user given data.
- <b>Web Audio API</b>: Used for playing the audio after giving a path.
- <b>HC CDN</b>: Used for storing all the songs to be fetched.
