# Suna
## About Suna:
#### Suna is a web application which can be used for you to just chill and listen songs, find your mood and get the song suggested and vibe on it and more. It has so much features which are given below.

<hr>

## Features:
- Listen Songs while having play, pause, rewind features.
- Find your mood and get the song related to it.
- Find the treasure song by looking at the lyrics.
- Explore different songs which are categorized into their artist.

<hr>

## Tech Stack:
- Node/Express Js
- HTML
- CSS
- JS
- Web Audio API
